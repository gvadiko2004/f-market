# F-Market

Адаптивная главная страница из Page 1, фрейм «Главная страница» (89:5).
Макет: https://www.figma.com/design/Fqr4sBeR6FSoWBikIS79Ca/f-market?node-id=89-5

## Запуск

Откройте `index.html` в браузере или запустите проект через Prepros. Сборка для просмотра не требуется. Шрифты Montserrat / Unbounded и изображения сохранены локально.

## Редактирование

- `index.html` — семантическая разметка и тексты.
- `scss/layout.scss` — оформление секций, адаптив, анимации.
- `scss/main.scss` — точка входа для Prepros; импортирует исходные ресеты и стили.
- `css/main.css` — готовый CSS для браузера. После правок SCSS пересоберите через Prepros.
- `js/main.js` — мобильная навигация, меню профиля, диалог, обработчик подписки, появление секций.
- `images/`, `fonts/` — локальные ассеты.

Десктоп повторяет композицию Figma; на планшетах и телефонах сетки перестраиваются. Добавлены клавиатурный фокус, переход к содержимому, доступные подписи и поддержка `prefers-reduced-motion`.

## Границы реализации

Это фронтенд главной, без сервера. Кнопки Steam открывают демонстрационный диалог. Для реальной авторизации подключите серверный Steam OpenID endpoint вместо обработчика `[data-auth]`. Данные формы подписки никуда не отправляются, форма честно сообщает об этом. Блог, партнёрская программа и юридические документы представлены диалогами до появления соответствующих страниц. Профиль achie_1, показатели и рейтинг воспроизводят макет, это не реальные данные вошедшего пользователя.

В макете сохранились упоминания DMarket, CS.MONEY, LisSkins и смешанные русский/украинский тексты — вёрстка их сохраняет. Ответы раскрывающегося FAQ добавлены как черновые тексты, поскольку в макете были только вопросы. Перед публикацией согласуйте тексты, цифры, условия выплат и юридические материалы.

## Проверка

Проверено в Chromium / Edge: 320, 375, 390, 768, 1024, 1440 и 1920 px; дополнительно проверена геометрия шапки при 430 и 760 px. Горизонтального переполнения и ошибок JavaScript нет; изображения загружаются. Проверены меню, FAQ, диалог с закрытием Escape и форма email. Иные браузеры и физические мобильные устройства не проверялись.
